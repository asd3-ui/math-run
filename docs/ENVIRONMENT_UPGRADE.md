# توثيق توسعة البيئة ثلاثية الأبعاد

## الهدف
توسيع إحساس المسافة والعمق في لعبة سباق الرياضيات دون استبدال منطق الأسئلة أو حفظ التقدم. جميع الأصول البصرية الجديدة تُنشأ محليًا باستخدام Three.js وCanvas API؛ لا توجد روابط نماذج خارجية مطلوبة لتشغيل البيئة.

## الملفات المتغيرة
- `src/world/Environment.js`: قبة سماء متدرجة، جبال بعيدة بطبقات parallax، سحب متحركة، أفق مدينة نيون، كوكب بحلقات في عالم الفضاء، وسلاسل جبال/براكين في العالم الناري. يظل لكل عالم تكوين إضاءة وضباب ومجسمات جانبية خاصة.
- `src/world/Track.js`: إسفلت مولّد محليًا، خطوط مسارات، أكتاف للطريق، حواجز وعواكس.
- `src/world/Player.js`: الشخصية ثلاثية الأبعاد ذات أطراف متحركة وانتقال بين المسارات.
- `src/world/Gate.js`: بوابات إجابات ثلاثية الأبعاد بإطارات معدنية وإضاءة محيطية.
- `src/world/Obstacle.js`: عوائق تختلف حسب العالم.
- `src/world/Particles.js`: غبار/جسيمات جوية بلون مختلف لكل عالم؛ تظهر النجوم في عالم الفضاء فقط.
- `src/core/Game.js`: إعدادات عرض متكيفة، حركة كاميرا متابعة، وربط الجسيمات بسرعة اللعبة والعالم النشط.
- `scripts/validate-game.js`: اختبارات انحدار للتحقق من بقاء العوالم الخمسة والمراحل المئة والوضع اللانهائي وقائمة الشخصيات.
- `.github/workflows/build.yml`: تشغيل اختبارات بيانات اللعبة ثم بناء نسخة المتصفح وAPK لأندرويد.

## ضمانات المحافظة على اللعب
لم يتم تغيير مولّد المسائل أو تعريف المراحل أو بيانات الشخصيات أو أسعار المتجر أو مفاتيح حفظ التقدم. اختبارات `npm test` تتحقق من عدد العوالم والمراحل، تفرد أرقام المراحل، وجود بيانات الصعوبة، وثبات معرّف الوضع اللانهائي والشخصية الافتراضية.

## البناء
```bash
npm install
npm test
npm run build
npx cap sync android
```

## حدود الواقعية والأداء
هذه توسعة إجرائية للمشهد وليست حزمة أصول AAA. للوصول إلى واقعية سينمائية أعلى، يمكن لاحقًا إضافة نماذج GLB مرخصة ومتحركة، وخامات PBR/normal/roughness عالية الجودة، وبيئات HDRI، وتحسينات post-processing اختيارية. يجب اختبار الإطارات والحرارة واستهلاك الذاكرة على أجهزة Android فعلية قبل رفع إعدادات الجودة افتراضيًا.


## تحسينات الأداء والاختبارات
- خامة الطريق أصبحت تستخدم خرائط لون وNormal وRoughness مولّدة محليًا.
- إعدادات الرسوم تتدرج بحسب زمن الإطار، ويمكن إظهار لوحة FPS وعدّادات Three.js بإضافة `?debug=1` إلى عنوان اللعبة.
- اختبارات `npm test` تتحقق من الأسئلة والبوابات والعوائق ومكافآت العملات، بالإضافة إلى بيانات المراحل.
- أضيف دعم اختياري لتحميل شخصية GLB متحركة عبر `game.player.loadAnimatedModel(url)`؛ يجب توفير ملف مرخّص بنفسك. لا يوجد نموذج سينمائي خارجي مضمّن في المستودع حتى الآن.

## اختبار Android
افتح اللعبة مع `?debug=1` وراقب FPS وزمن الإطار وعدد المثلثات وdraw calls وعدادات المجسمات والخامات. بعض إصدارات Android WebView لا تكشف ذاكرة JavaScript، وعدادات Three.js ليست قياسًا كاملًا لذاكرة GPU. اختبر على جهاز فعلي قبل تحديد الجودة الافتراضية.
