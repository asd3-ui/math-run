# 🏃 سباق الرياضيات 3D

لعبة تعليمية عربية ثلاثية الأبعاد بأسلوب Endless Runner. تعمل في المتصفح ويمكن تثبيتها كتطبيق ويب تقدمي (PWA) على الأجهزة المتوافقة.

## الوظائف المحفوظة

- 100 مرحلة ضمن خمسة عوالم، مع وضع لا نهائي.
- مسائل حسابية متدرجة، وثلاثة مسارات للإجابات.
- 6 شخصيات قابلة للاختيار والفتح.
- متجر العملات وأدوات التجميد وحذف الإجابة والدرع والقلب الإضافي.
- العملات، القلوب، الـ Combo، التقدم والإحصاءات محفوظة في `localStorage`.
- صوت وموسيقى ومؤثرات، إيقاف مؤقت، دعم العربية RTL والتحكم باللمس ولوحة المفاتيح.

## تحسينات الرسوم ثلاثية الأبعاد

- بيئات إجرائية محلية لكل عالم؛ لم تعد البيئة تعتمد على روابط GLB خارجية غير مضمونة أو على CORS.
- طريق بخامة إسفلت مولّدة محليًا، وخطوط متقطعة وأكتاف وحواف وعواكس.
- إضاءة محيطية من السماء والأرض، وظلال محسّنة، وخامات PBR، وتفاصيل إضافية للشخصية.
- إعدادات عرض قابلة للتكيّف مع شاشات الهاتف لتقليل كلفة الرسم.

> ملاحظة: هذه التحسينات ترفع جودة المشهد باستخدام المجسمات الإجرائية المضمّنة. الوصول إلى واقعية AAA فعلية يحتاج لاحقًا إلى أصول فنية احترافية (نماذج بشرية مُحركة، خامات PBR عالية الدقة وبيئات HDRI) مع تراخيص واضحة وقياس الأداء على أجهزة فعلية.

## التشغيل

يتطلب Node.js حديثًا:

```bash
npm install
npm run dev
```

لبناء نسخة الإنتاج:

```bash
npm run build
npm run preview
```

## الاختبار

يُشغّل GitHub Actions عملية تثبيت التبعيات وبناء `dist` عند كل دفع إلى الفروع أو طلب سحب. يجب التأكد من نجاح التشغيل الفعلي في صفحة Actions قبل اعتبار النسخة مختبرة.
