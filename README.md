# 🏃 سباق الرياضيات 3D — v2.1

لعبة تعليمية ثلاثية الأبعاد بأسلوب Endless Runner — اركض، فكّر، واختر الإجابة الصحيحة!

## ✨ الميزات

- 🎮 **12 مرحلة** بصعوبة متزايدة (جمع → طرح → ضرب → قسمة → مختلط)
- ♾️ **وضع لا نهائي** للاعبين المتمرسين
- 👕 **6 شخصيات** قابلة للفتح والاختيار
- 🎵 **موسيقى خلفية مُولّدة** + 8 مؤثرات صوتية
- 🌟 **جسيمات ثلاثية الأبعاد** + نجوم متحركة
- 🎨 **بيئات متغيرة** لكل مرحلة
- 🔥 **نظام Combo** يضاعف النقاط
- 🛒 **4 مساعدات**: تجميد، حذف إجابة، درع، قلب إضافي
- ⏸ **إيقاف مؤقت** أثناء اللعب
- 💾 **حفظ كامل** للتقدم في المتصفح
- 📱 **دعم كامل للعربية RTL** والتحكم باللمس
- 📲 **PWA جاهز** للتثبيت على الجوال والعمل بدون إنترنت
