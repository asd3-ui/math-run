# 🏃 سباق الرياضيات 3D — v2.0

لعبة تعليمية ثلاثية الأبعاد بأسلوب Endless Runner — اركض، فكّر، واختر الإجابة الصحيحة!

## ✨ الميزات

- 🎮 **12 مرحلة** بصعوبة متزايدة (جمع → طرح → ضرب → قسمة → مختلط)
- ♾️ **وضع لا نهائي** للاعبين المتمرسين
- 👕 **6 شخصيات** قابلة للفتح والاختيار (آدم، ليلى، البطل، النينجا، الروبوت، رائد الفضاء)
- 🎵 **موسيقى خلفية مُولّدة** + 8 مؤثرات صوتية (صحيح، خطأ، عملة، انتصار...)
- 🌟 **جسيمات ثلاثية الأبعاد** عند الإجابة الصحيحة/الخاطئة + نجوم متحركة
- 🎨 **بيئات متغيرة** لكل مرحلة (سماء + أرضية)
- 🔥 **نظام Combo** يضاعف النقاط مع كل إجابة صحيحة متتالية
- 🛒 **4 مساعدات**: تجميد، حذف إجابة، درع، قلب إضافي
- ⏸ **إيقاف مؤقت** أثناء اللعب
- 💾 **حفظ كامل** للتقدم والعملات والشخصيات في المتصفح
- 📱 **دعم كامل للعربية RTL** و**التحكم باللمس** على الجوال
